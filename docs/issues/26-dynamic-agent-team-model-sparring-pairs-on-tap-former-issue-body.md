# Dynamic agent-team model: sparring pairs, on-tap domain experts, spy-triaged oversight (design capture; research pending)

## What this tracks

The dynamic agent-team model — NC's post-boot answer to agent organization, boss-designed 2026-07-25 (outer walk item 16, superseding the org-chart possibility captured in pair GHI [Working ideas and research backlog — capture pair (Decided / Candidate / Research / Reference)](https://github.com/nedschorus/nedschorus/issues/10)). Substance: the paired document `docs/issues/26-dynamic-agent-team-model.md` (number assumed at filing; corrected in the same commit if GitHub assigns differently).

One-line shape: task-scoped worker agents + on-tap domain-knowledge agents + SDLC skills carried by workers and subagents; cross-runtime **sparring pairs** (cooperate as driver/guardian — the guardian covers the driver's back, protective never antagonistic — compete as N-version teams on hard tasks, reconcile at phase boundaries); cheap **spy** watchers triaging a filtered intent-stream to domain experts; PM agents as the boss's interface. Goal: **context engineering** — every agent gets the context it needs, none of the burden it doesn't. Standing principle: every agent needs oversight all the time, by a differently-contexted observer.
