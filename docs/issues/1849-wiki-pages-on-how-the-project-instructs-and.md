## Why

Agents follow an instruction only when they remember it at the moment it applies. An instruction read at the start of a long agent-session fades as the context fills, and a rule only stored is never read. So the project tells agents what to do just in time, keeps each agent's context focused on its current step, and breaks big recurring tasks into small, clear steps, which together make the software development life cycle a large state machine of small states. The techniques page is meant to say how that is done, and how to choose a technique for a new problem. This is the argument of the overview the user is writing; his draft of it heads the techniques page now, under "Overview: SDLC is a large, complex state machine".
