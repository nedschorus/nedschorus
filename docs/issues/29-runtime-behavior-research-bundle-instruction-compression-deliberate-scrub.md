Captured, not scheduled; lean bundle rather than nine micro-issues.

1. Instruction-compression experiments: try smaller CLAUDE.md, AGENTS.md, and wiki files while measuring whether FRESH-AGENT BEHAVIOR loses essential rules. Fewer words alone is not success — behavior is the measure. Feeds the step-2 CLAUDE.md rewrite.

3. Instruction-file precedence: review our instruction files for conflicts with the runtimes' own system-level instructions, and establish actual precedence by probe, not assumption.

6. Message-loss recovery: if backward resumption can lose already-consumed messages, determine how to recover the evidence from the transcript or the durable handoff.
7. A small reviewer for conflicting or ambiguous names — a writing-time collision catcher. Build candidate, not research.
8. Memory maintenance: evaluate a dedicated program or API against maintenance-as-discipline.
9. Memory entries pointing at exact wiki pages: does it measurably improve retrieval?
