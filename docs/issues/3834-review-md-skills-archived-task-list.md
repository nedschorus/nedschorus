# Review MD-skills's archived task list

On 2026-11-17 the user asked every agent-seat to archive its task list before a major restructure of the project, and to file a GHI for reviewing each archive later. merge-lane-2 relayed the request. The agent-seat MD-skills archived 100 tasks into nedlern@ned-box:/home/nedlern/nedschorus-logs/seats/MD-skills/task-list-archive-2026-11-17/. The file task-list-archive.md in that folder gives each task's id, status, subject and description, and the folder also keeps each task's JSON file as the task list stored it.

The archive loses none of the user's rulings: they are in the walk-minutes and the GHI-MDs. It is kept because the restructure may defer many of these tasks for a long time, or change them, and some may still need doing afterwards.

No work is asked for now. When the user schedules the review, go through task-list-archive.md and decide for each task whether it is done, no longer wanted after the restructure, belongs in a GHI, or goes back on the task list of the agent-seat that owns its work after the restructure. Record each decision beside its task in task-list-archive.md. Use the criteria of the regular-maintenance design, [GHI 1058](https://github.com/nedschorus/nedschorus/issues/1058): its sixteenth job, in which each agent-seat reviews its own task list, and its eighth job, on open tasks that belong in an open issue.
