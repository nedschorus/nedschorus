# Riders for pair #20 (implement-with-evidence) — from the agent-native testing walk

Queued for the boss's drain (promote / edit / demote / drop). Source: `nc-queue/2026-07-28-sdlc-skill-set-coverage-and-app-skill-pile.md` §6a items 2 and 4 (boss-walked 2026-07-29/30). Destination: [nedschorus#20](https://github.com/nedschorus/nedschorus/issues/20).

1. **One-shot creators, retained for interrogation (boss-ruled).** Code and test writing is done by one-off agents: a creator's context is poisoned as a judge by its assumption of success, so it never reviews its own work. Its session ID (a short string; the transcript jsonl persists) is retained until the work clears checks **or 30 days elapse, whichever comes first** (boss-ruled 2026-07-30 — the interrogation window rides inside the drop discipline), so the creator can be resurrected as an **evidence source**: when a checker finds a problem, interrogate the creator with the blameless framing — "the goal is not an apology; was your instruction set confusing, incorrect, or lacking?" Findings land upstream (design text, skill prompts, wiki, CLAUDE.md), because every future agent inherits the same boot context — one context patch corrects the population.
2. **Test writers are implementation-blind.** The agent writing tests receives the design, contracts, and error catalog — not the implementation — so implementation-mirroring tests are structurally impossible, and each test's declared red condition is derived from the design rather than transcribed from code.
3. **Branch-frequency posits written at implementation time (boss-ruled).** Every branch (control-flow-graph edge) gets a frequency-class posit (HOT / NORMAL / RARE / NEVER-except-emergency) written while the author-agent's context is fresh; numeric posits (relative to the enclosing function) only where the design states a frequency. Posits are predictions with provenance (design-claim ref or dated author-judgment) — written before consulting measurement. Full mechanics and mismatch verdicts: pair #35's ladder record.
