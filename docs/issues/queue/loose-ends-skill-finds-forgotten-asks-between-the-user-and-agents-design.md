# Loose-ends skill: each agent-seat finds what was asked, offered or left open in its conversations that nothing tracks, and does its own critical upkeep

## Why

The user runs many agent-seats at once and reads each one only now and then. Things that one side asked of the other get lost: an agent waits on a question the user never saw, could not follow, or did not need to be asked; the user asks for something that is acknowledged and never done; a task that says to bring something to the user sits for days, which D10, below, leaves to the task list. Parts of this are caught today, each in one place only: /walk-me-through's "Closing" section makes the agent check one approval-walk for its own unanswered questions and open commitments before the approval-walk closes; /handoff step 1 makes the agent bring its task list up to date, with each question for the user that no approval-walk holds as a task. Nothing reads an agent-seat's conversations for what was lost between them. Agents have twice gathered such items by hand, as one-off approval-walks: merge-lane's `nedlern@ned-box:/home/nedlern/nedschorus-logs/walk/2026-08-31-session-loose-ends.md` and MD-skills' `nedlern@ned-box:/home/nedlern/nedschorus-logs/walk/seat-loose-ends-and-stale-tasks-2026-09-18.md`.
