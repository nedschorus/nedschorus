# Fixed markers list for the hashtag review

This file holds steps 1 to 3 of GHI [Review the whole project for fixed markers that would be clearer as hashtags](https://github.com/nedschorus/nedschorus/issues/1518), whose GHI-MD is `docs/issues/1518-review-the-whole-project-for-fixed-markers-that.md`: every fixed marker an agent or a program looks for, where it is written, what reads it, what a change to a hashtag would break, and a recommendation to keep it or change it. Each section covers one system; an agent-seat that inventories another system adds a section of its own. Nothing here is renamed yet: step 4 of the GHI-MD puts each recommendation to the user in an approval-walk.

A fixed marker here is text that crosses a boundary: one program's output that another program matches, a phrase in a prompt that a program later finds in a transcript, a file an agent writes that a program parses, or a line agent-instructions tell an agent to write or look for. Values compared only inside one program's memory are left out, as is text both sides build with one shared function, such as the launch-time-git-sync stop line `nc-systems/handoff/handoff-supervisor.py:295-301` tests for, such as the verdict strings `seat-already-running`, `restart`, `offer` and `stamped-since-boot`, state JSON keys, environment variable names and filename suffixes.

A proposed hashtag follows the form the GHI-MD proposes and the existing hashtags `#root_cause`, `#pre_approved_change`, `#next_to_present` and `#item_page` use: `#`, then lowercase words joined by underscores, naming what the line is, placed at the start of the line it marks, or, for a mark on text inside a line, right after that text. How each hashtag sits beside the words a person reads, and how each parser changes, is settled in the pull request that makes the change. "Readers" counts the tests that quote the literal, because each breaks when the literal changes.

Three readers already give a line that opens with `#` a meaning of their own, so a hashtag placed at the start of a line must change each reader that would meet it in the same pull request: `nc-systems/handoff/handoff-supervisor.py:606` skips a handoff-file line that starts with `#` as a comment; `scripts/agent-seat-idle-sweep-verdicts-print.py:187-192` drops heading marks and then skips any line still starting with `#`, so an agent's turn-ending sentence written after a line-start hashtag is never checked for a promise; and `nc-systems/skills/walk-me-through/walk-me-through-agent-question-to-user-outside-approval-walk-items-refusal-stop-hook.py:225` and `:373` strip a leading `#word ` before judging whether a line asks the user something.
