# design-to-main agent-instructions — drafts
These files are the standing-agent-instructions the design-to-main state machine (`docs/design-to-main/design-to-main-state-machine-design.md`; "§N" in every file cites it) launches each agent with: one file per state or sub-state that launches an agent, named `design-to-main-<state>-agent-instructions.md`, drafted 2026-09-08 from the design and its glossary.
They are drafts in `docs/agents/queue/`, awaiting their full cold reads and the user's review, and land in `docs/agents/` after both (user-ruled 2026-09-08); nothing launches them yet.
Which state launches which: `design-writing` launches the initiator; `contract-revising`, `implementation-writing`, `test-design-writing` and `test-writing` each launch a writer; `design-acceptance-by-agent`, `contract-acceptance-by-agent`, `implementation-acceptance-by-agent`, `test-design-acceptance-by-agent` and `test-acceptance-by-agent` each launch a reviewer; `test-suite-arbitrating` launches the arbitrator, which then holds every later entry to that state and every investigation opened while it lives, `investigate-workflow` using the same file, and a fresh arbitrator is launched only when none lives (§6.5, §6.6).
Common to all, who lives and who is fresh (§1, §7): an agent lives through its design version — the first entry to its state launches it, later entries in that version return to it with the notes or the diff — and a fresh agent takes its place at a redesign, past a writer's ceiling, or when a zeroing of the counters, which is a resume from an investigation or the user's `reset`, refreshes every writer and reviewer, the agent talking to the user excepted (user-ruled 2026-09-11).
Common to all, the state-exit (§2): one state-package in, one state-exit out, the file `state-exit.json` in the directory the state-package names as `evidence-directory`, beside `notes.md` — `state`; a `verdict` from the state's own list; `package-commit` copied from the state-package; `destination` only where the agent names one, which these drafts do on `resume` alone (§6.1); the field the verdict needs, `input-named` (`design`, `component-contract`, `test-design`), `investigation-focus` (`design`, `test-design`), `coverage-type` (one value for an implementation, and every type present in a set of tests) or `held-ruling` (`refusal-class` is `submit-to-PR-gate`'s, which launches no agent); and `named-files`, the artifact files the commit carries, since what no state-exit names and the record does not hold is discarded after the commit (§9). The record directory, which holds the notes, the state-exit and a reviewer's own tests, is committed whole, so nothing in it is named. A field the design does not name is refused. The two agents that talk to the user, the initiator and the arbitrator, also carry his rulings in `rulings`, verbatim, and the machine appends them to the user-rulings file.
Common to all, the notes: one file, `notes.md`, in the instance's evidence directory, `<component's directory>/design-to-main-record/evidence/<state or sub-state>-<n>/`, n counted from 1 over the run (§9), a reviewer's own tests beside it; findings carry a failure scenario, nits sit under a `Nits` heading and are not routed as work (§6.1). The component's directory exists from the topic branch's cut, holding only `design-to-main-record/`; the design and the component-contract sit in `docs/designs/queue/` until `implementation-writing` is first entered, when the machine moves them in (§9).
Common to all, the state-package (§2): the standard-package — the design, the component-contract and the user-rulings file `<component's directory>/design-to-main-record/user-rulings.md`, whose latest ruling on a point governs and which nobody re-raises — plus what §3.1's Package column names for the state, repeated in its file.
Common to all: no agent commits or pushes — the machine commits every state-exit to the topic branch (§9); no agent below the design edits the design; a reviewer edits nothing at all.
Every example is built on the `create-topic-branch` component and its refusal-clause-pair 7a/7b: no `origin/main` after the fetch, exit status 1, two stderr lines, stdout empty.
The drafts follow the design as it stands on `main` after PR #322 (2026-09-11), which carried the ninth walk's rulings.
