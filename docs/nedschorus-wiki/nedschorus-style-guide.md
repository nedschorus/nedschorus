# Style guide

This page lists words to avoid in this project and what to write instead. Most of the words below each name several different things here, so a reader cannot tell which one the writer meant; "land" has a project word that replaces it; the pronouns leave a reader who lacks the writer's context guessing what each stands for. A listed word used in its ordinary English meaning stays, as does a word inside code, inside double quotes, or mentioned rather than used, as in the table's first column.

`scripts/style-guide-word-checker.py` reads the table below. After an agent's Edit or Write of a markdown file, `scripts/style-guide-word-checker-markdown-edit-hook.py` reports each listed word in the text just written, and the writer decides whether each hit needs changing. Changing a row changes what the hook reports. A form is also reported with a capital first letter, such as "Seat" at the start of a sentence; besides the forms in the third column, the checker skips code, link targets, paths and text in double quotes.

## Words to avoid

| Word | Forms flagged | Forms not flagged | Write instead | Applies to |
|---|---|---|---|---|
| `land` | `land`, `lands`, `landed`, `landing` | | "merge", "merges", "merged" or "merging", matching the form written | files, messages to other agents, messages to the user |
| `home` | `home`, `homes` | `agent-home`, `/home/`, `home directory` | agent-home for the directory an agent-seat works in; canonical location for the one authoritative place a document or fact is kept | files, messages to other agents, messages to the user |
| `draft` | `draft`, `drafts` | `-draft`, `docs/drafts/`, `draft pull request` | -draft for the filename suffix; "pending approval" for text that waits for the user's approval; "the `draft` label" for the GitHub label; `docs/drafts/` for the directory | files, messages to other agents, messages to the user |
| `walk` | `walk`, `walks`, `walked`, `walking` | `approval-walk`, `approved-by-walk`, `walk-document`, `walk-minutes`, `/walk-me-through`, `docs/walk/` | approval-walk for the event; walk-document for the file `docs/walk/<name>.md`; approved-by-walk for what the user approved in an approval-walk; "put to the user in an approval-walk" for the act | files, messages to other agents, messages to the user |
| `seat` | `seat`, `seats`, `seated` | `agent-seat`, `seat-branch`, `seat-brief`, `reincarnate-seat`, `retire-seat` | agent-seat for the identity; agent-session for one running conversation; "the agent-seat's name" for the name of an agent-seat; working directory for where an agent-session works when that is not its agent-seat's agent-home; cold-read-cell for one reviewer in a cold-read-full-run | files, messages to other agents, messages to the user |
| `head` | `head`, `heads` | `head commit`, `frozen-head`, `HEAD`, `head branch` | head commit for the commit at the tip of a pull request's branch; frozen-head when the point is that the pushed head commit must not be amended; `HEAD`, in capitals, for what a Git checkout has checked out | files, messages to other agents, messages to the user |
| `drain` | `drain`, `drains`, `drained`, `draining` | `queue-drain` | queue-drain for the procedure that empties the four queue directories and `docs/drafts/`; "is promoted to" for an item that leaves a queue for its approved location | files, messages to other agents, messages to the user |
| `issue` | `issue`, `issues` | `GitHub issue`, `issue-marker`, `/issues/`, `gh issue` | GHI for a GitHub issue; "problem", "defect" or "concern" for something wrong | files, messages to other agents, messages to the user |
| `it` | `it` | | the noun the pronoun stands for, unless the noun is in the same sentence and no other noun there could be meant; a pronoun with no noun behind it, as in "it is raining", stays | messages to other agents, messages to the user |
| `its` | `its` | | the noun the pronoun stands for, unless the noun is in the same sentence and no other noun there could be meant; a pronoun with no noun behind it, as in "it is raining", stays | messages to other agents, messages to the user |
| `they` | `they` | | the noun the pronoun stands for, unless the noun is in the same sentence and no other noun there could be meant; a pronoun with no noun behind it, as in "it is raining", stays | messages to other agents, messages to the user |
| `this` | `this` | | where "this" is used as a pronoun, the noun it stands for, unless the noun is in the same sentence and no other noun there could be meant; a pronoun with no noun behind it, as in "it is raining", stays | messages to other agents, messages to the user |
| `that` | `that` | | where "that" is used as a pronoun, the noun it stands for, unless the noun is in the same sentence and no other noun there could be meant; a pronoun with no noun behind it, as in "it is raining", stays | messages to other agents, messages to the user |

"Applies to" names where the word is avoided: files, messages to other agents, and messages to the user. The pronoun rows apply to messages only, which CLAUDE.md's pronoun bullet governs; the hook checks files only, so no program checks the pronoun rows yet.
