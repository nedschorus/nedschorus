Check newly invented names with glob (for path names), grep (for names in files), or a gh search (for issue, PR, and branch names). If these checks return collisions or ambiguity, choose a more explicit name, with 3 or 4 parts, not 1 or 2. If the thing you are naming already has a name in the project, use the existing name instead of inventing a new one.
